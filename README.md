# PFC管理

今日のたんぱく質(P)・脂質(F)・炭水化物(C)の摂取量と目標をひと目で確認し、食べたものを素早く記録する個人用アプリです。
iPhone の Safari で「ホーム画面に追加」して、ふつうのアプリのように使います。

- サーバもアカウントもありません。データはすべて **この iPhone の中** にだけ保存されます(通信・同期なし)。
- ビルド不要・外部ライブラリなし。`index.html` 1 ファイルで動くので、あとから AI に手伝ってもらって直せます。

## ファイル構成

```
index.html            … アプリ本体(HTML / CSS / JS を 1 ファイルに同梱)
manifest.webmanifest  … ホーム画面アプリ用の設定(名前・アイコン)
sw.js                 … 圏外でも開けるようにする仕組み(Service Worker)
icons/                … アイコン画像(180 / 192 / 512px)
README.md             … このファイル
仕様書.md             … 仕様書(AI に直してもらうときに渡す)
tests/                … 動作確認用のテスト(公開には不要。アップロードしなくてよい)
```

## 1. GitHub Pages に置く(ブラウザだけで完了します)

1. https://github.com で無料アカウントを作ります(すでにあればログイン)。
2. 右上の「＋」→ **New repository**。Repository name に `pfc` と入力し、**Public** を選んで **Create repository**。
3. できたページの「**uploading an existing file**」リンクを押します。
4. このフォルダの `index.html`・`manifest.webmanifest`・`sw.js`・`README.md`・`仕様書.md` と **`icons` フォルダごと** ドラッグ&ドロップします(フォルダを落とすと中の画像も一緒に入ります)。
5. 下の **Commit changes** を押します。
6. リポジトリの **Settings** → 左の **Pages** → Source を「**Deploy from a branch**」、Branch を「**main**」/「**/ (root)**」にして **Save**。
7. 数分待つと `https://<あなたのユーザー名>.github.io/pfc/` で開けます(同じ Pages 画面に URL が表示されます)。

## 2. iPhone のホーム画面に追加する

1. Safari で上の URL を開きます。
2. 画面下の **共有ボタン(四角に↑)** → 「**ホーム画面に追加**」→ 右上の「**追加**」。
   iOS 26 以降で「Webアプリとして開く」というスイッチが出たら **オンのまま** にしてください。
3. **以後は必ずホーム画面のアイコンから開いてください。** Safari のタブとホーム画面アプリでは保存領域が別なので、タブで開くと記録が空に見えます(別のデータになります)。

## 3. 毎日の使い方

画面の一番下に 5 つのタブがあります。左から **記録 / マイ食品 / ホーム / 買い物 / 値段** です。
開くといつも **ホーム** から始まります。どのタブも右上の ⚙ が設定です。

### ホーム(まん中のタブ)

- 上から、**今日の P / F / C と kcal**、**直近 7 日の達成率**、**1 週間の平均**(記録のある日だけで計算し、目標と並べて表示)、**1 週間の推移グラフ**(kcal / P / F / C を切替。破線はその日の目標)。
- 下のほうの「**記録する**」から、セット・マイ食品・最近の記録のチップや「＋ 記録する」で追加できます。ここから入れた記録は **いつも今日** に入ります。
- 7 日の列をタップすると、記録タブのその日が開きます。

### 記録

- その日の記録を見る・追加する・直す画面です。ヘッダの「‹」「›」で前後の日へ、日付をタップすると今日に戻ります。過去の日にも追記できます(時刻の初期値は 12:00)。
- **記録する**: 画面下の「＋ 記録する」→ 名前(任意)と P / F / C(g)を入れて「保存」。パッケージの栄養成分表示と同じ順(P → F → C)です。
- **最近の記録**: 直近 30 日に記録したものがチップで並びます。タップするとその場で同じ内容を追加します(5 秒以内なら「元に戻す」)。
- **編集・削除**: 一覧の行をタップ → 直して「保存」、または「この記録を削除」。
- **達成判定**: たんぱく質は「以上でOK」(目標に届けば緑)、脂質・炭水化物は「以下でOK」(超えると赤、超えた分はバーの右端に縞)。設定で栄養素ごとに切り替えられます。
- 目標を変えると **今日以降** に適用され、過去の日はその日の目標のまま表示されます。

### マイ食品

上の切替で「**マイ食品 / セット / PFC未登録**」を選びます。

- **マイ食品**: よく食べるものを登録しておくと、チップをタップ → 杯数や g を指定 → 「追加」の 2 タップで記録できます。記録シートの「この内容をマイ食品に登録」からも登録できます。
  「値段の単位」(1個あたり / 100gあたり)は、値段タブで比べるときの単位です。
- **セット**: 毎朝の朝食のように決まった組み合わせを、まとめて記録できます。中身はマイ食品です。
  - 作り方: 「＋ 新しいセット」→ 名前 →「＋ 食品を追加」でマイ食品を選んで量を決める →「保存」。
  - 使い方: セットのチップをタップ → 中身を確認(食べなかった品はチェックを外す、量を変える)→「追加」。1 品ずつ別の記録になり、5 秒以内なら「元に戻す」でまとめて取り消せます。確認画面で変えた量はその回だけです。
- **PFC未登録**: 買い物リストで「食品(PFCはあとで)」として追加した食品です。P/F/C がまだ無いので、チップや一覧には出ません。
  「**PFCを入れる**」から基準と P/F/C を入れて保存すると、ふつうのマイ食品になります。件数はタブと切替のバッジに出ます。

### 買い物

- 上の欄に買うものを入力します。マイ食品(PFC未登録を含む)や前に入れた品の名前が候補に出るので、タップするとリストに入ります。
- 候補に無い名前は、種類を選んで「追加」: **食品(PFCはあとで)** ならPFC未登録の食品になり、**食品ではない**(洗剤など)ならその品だけ覚えます。
- 「**よく買うもの**」のチップは、リストに入れた回数の多い順です。タップでリストに戻せます。
- 行の右の「数量」をタップすると、「2パック」のようなメモを入れられます。
- **チェックを付けると「買った」シート**が開きます。店を選び(初期値は前回の店。「＋ 新しい店」でその場で作れます)、値段を入れて「保存」。
  100gあたりの品は「金額」と「グラム」を入れると、100gあたりの値段がその場で出ます(例「¥350 / 200g → 100gあたり ¥175」)。1個あたりの品は金額だけです。
  値段を入れたくないときは「値段は入れない」でチェックだけ付きます。
- 買った行は薄くなって下に移ります。チェックを外すと未購入に戻ります(値段は残ります)。
- 「**安い店ごとに分ける**」をオンにすると、一番安い店ごとに分けて並べます(値段が無い品は「値段未登録」)。
- 「**買ったものを片付ける**」で、チェック済みの行をまとめて消します(5 秒以内なら「元に戻す」)。
- 行の名前をタップすると、数量メモ・値段の単位の変更、「リストから外す」、(食品ではない品なら)名前の変更と削除ができます。
- 未チェックの品の数は、タブのバッジに出ます。

### 値段

- 値段を入れた品が、品名順のカードで並びます。標準では **一番安い店と値段** だけを大きく表示します(例「業務スーパー ¥175/100g」「10/1 更新」)。
- カードをタップすると、すべての店が安い順に開きます(1 位に「最安」)。上の切替を「すべての店」にすると全部のカードが開きます。
- 店の行をタップすると、その値段を直したり削除したりできます。
- 「**＋ 値段を追加**」で、品(マイ食品・食品ではない品・新しい名前)・店・値段を選んで入れられます。同じ品と店の値段は上書きされます(最新の値段だけを持ちます)。
- 上の検索欄で品名を絞り込めます。
- 「**店を管理**」で店の追加・名前の変更・削除ができます。名前を変えるとすべての画面に反映されます。**店を削除すると、その店の値段も消えます。**
- マイ食品や食品ではない品を削除すると、その品の値段と買い物リストの行も消えます(確認が出ます)。
- 値段の単位(1個あたり / 100gあたり)を変えると、それまでの値段は比べられなくなるので消えます(確認が出ます)。

## 4. バックアップ(定期的に)

データは iPhone の中にしかありません。**週に 1 回くらい** バックアップしてください(14 日以上していないと画面上に案内が出ます)。

**書き出す**
1. 設定(⚙)→「**ファイルに書き出す**」。
2. 共有シートで「**"ファイル"に保存**」→ **iCloud Drive** の好きなフォルダに保存(`pfc-backup-日付.json`)。

**復元する(機種変更や消えてしまったとき)**
1. 新しい iPhone でアプリをホーム画面に追加して開きます(初回画面のままで OK)。
2. 設定 →「**ファイルから読み込む**」→ 保存しておいた `pfc-backup-….json` を選ぶ → 確認で「OK」。
3. 記録・マイ食品・セット・目標・買い物リスト・店と値段がそのまま戻ります(セット機能や買い物機能より前の古いバックアップもそのまま読み込めます)。

「テキストとしてコピー」「テキストから読み込む」は、JSON をメモ帳などに貼って持ち運ぶ方法です。

## 5. アプリを更新したとき

**新しい版は、アプリを開いたときに自動で届きます。** 操作は要りません。

- アプリを開いたときや、裏から前に戻したときに新しい版を確認し、**入力中でなければその場で切り替わります**(「新しいバージョン(1.2.0)になりました」と 1 回だけ出ます)。
- 入力中(シートを開いている・入力欄を触っている・「元に戻す」が出ている)なら、終わった時点で切り替わります。記録は端末に保存されているので消えません。
- 確認は 5 分に 1 回まで。すぐ確かめたいときは、設定 →「**更新を確認**」か、画面下の「新しいバージョンがあります [更新]」を押してください。

**新しい版を公開する人(自分で直したとき)の手順**
1. `index.html` の `APP_VERSION`(例 `'1.2.1'`)と `sw.js` の `CACHE`(例 `'pfc-v1.2.1'`)を **両方** 新しい番号にします。
2. GitHub のリポジトリページで **Add file → Upload files** から変更したファイルをドラッグ&ドロップし、**Commit changes**(同じ名前のファイルは上書きされます)。
3. 数分後、iPhone でアプリを開けば自動で新しい版になります。

## 6. 注意

- **データはこの iPhone の中だけ** にあります。iCloud 同期やサーバ保存はありません。
- **ホーム画面のアイコンを削除するとデータも消えます。** 先にバックアップを取ってください。
- **URL が変わると別の保存領域になります**(リポジトリ名を変える、別のアカウントに移す、など)。移す前に書き出し、移した後に読み込んでください。
- kcal は **P×4 + F×9 + C×4** の計算値です。パッケージの熱量表示と数% ずれることがあります。
- Safari の「履歴と Web サイトデータを消去」を実行すると、ホーム画面アプリのデータも消えることがあります。
- 「保存できませんでした」と出たら、空き容量不足かプライベートブラウズです。ホーム画面のアイコンから開き直してください。
- 起動時に「保存データを読めなかった」と出たら、元データは `pfc.corrupt` に退避されています。バックアップから読み込んでください。

## 開発メモ(AI に直してもらうとき)

- `index.html` の `<script id="core">` には DOM に触れない純粋関数(計算・日付・検証・値段の比較)、`<script id="app">` には画面と保存の処理があります。仕様は `仕様書.md`。
- 保存データは localStorage の `pfc.v1` キーに JSON で入っています(形式は仕様書 4 章・12 章・13.5)。`version` は 1 のままです。
- セット機能(v1.1.0)は仕様書 12 章。`sets` 配列に入っていて、中身はマイ食品の id と量だけ(値は毎回マイ食品から計算)。
- タブ構成・買い物・値段・自動更新(v1.2.0)は仕様書 13 章。
  - マイ食品に `pending`(PFC未登録)と `priceBasis`(値段の単位)、新しく `stores`(店)・`goods`(食品ではない品)・`prices`(品 × 店の最新の値段)・`shopping`(買い物リスト)の配列が増えました。
  - 「よく買うもの」の並び順のため、マイ食品と goods に `shopCount`(買い物リストに入れた回数。1 以上のときだけ)を持たせています(仕様書に無い追加の項目)。
- テストは `tests/` にあります(Mac + Node.js 22 + Google Chrome が必要)。全部まとめて流すときは:
  ```
  cd tests
  TZ=Asia/Tokyo node unit.js && TZ=Asia/Tokyo node sets-unit.js && TZ=Asia/Tokyo node v12-unit.js && TZ=America/Los_Angeles node v12-unit.js
  node scenario.js && node robust.js && TZ=Asia/Tokyo node fixes.js && node sets.js && node shots.js && node tabs.js && node shopping.js && node pfccols.js && node typing.js
  ```
  - `unit.js` / `sets-unit.js` / `v12-unit.js` … core の関数のテスト(ブラウザ不要)
  - `scenario.js` / `robust.js` / `fixes.js` / `sets.js` / `shots.js` … v1.0〜v1.1 の画面のテスト
  - `tabs.js` … タブ・ホーム・PFC未登録・自動更新、`shopping.js` … 買い物リスト・値段・店の管理・書き出し/読み込み
  - スクリーンショットは `tests/out/` に保存されます。Chrome が残ったときは `pkill -f "pfc-cdp-"`。
